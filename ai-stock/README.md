# AI Stock Analysis

## Prompt:
```
寫一個台灣股票分析師HTML,輸入股票代號，依據該公司財報，整合近期股價，新聞資訊搜尋https://m.cnyes.com/news，以專業的證卷分析師角色，產生股價走勢圖，做出技術分析，及專業的股票趨勢分析報告
```

`python app.py`<br>

Open your browser to `http://localhost:5000`<br>
