## Game design using Godot
`Godot` <br>

### Create Godot-MCP server
```
cd ~/AgenticCoding/game-godot
git clone https://github.com/ee0pdt/Godot-MCP/
```
#### Prompt:
```
study ./Godot-MCP and add Godot-MCP server to opencode
```
#### restart OpenCode 
enable Godot-MCP server<br>
```
/mcps
```
